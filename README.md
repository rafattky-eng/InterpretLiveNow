# InterpretLiveNow  V1.0.3
Japanese ⇄ English live interpreter (iPhone PWA). All files live in one folder (no sub-folders).

## Deploy (GitHub Pages)
1. Upload all files to a repo, branch `main`.
2. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
3. Open the site in Safari on iPhone → Share → Add to Home Screen.
